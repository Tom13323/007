# 007

**Only one shall stand.** Wanna gamble your luck? A simultaneous-move duel against 1, 2 or 4 bots. Every round you pick one action. The larger the risk, the greater the gain. Hope you can be the last one standing.

## Actions
- **Reload** +1 bullet (dies to any attack)
- **Shoot** 1 bullet
- **Defense** blocks Shoot and Bomb
- **Bomb** (players − 1) bullets, hits everyone
- **Reflect** once per game, kills attackers
- **Machine Gun** 10 bullets, unstoppable

Opposing bullets cancel out. Last one alive wins.

🤫 **Hidden rule:** Machine Gun vs Shoot is a tie.
